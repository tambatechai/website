# tambatech.ai

Website of Tamba Tech, an applied AI hub in the US and Brazil.

Static site: `index.html`, `assets/css/style.css`, `assets/js/main.js`. No build step.

Run locally:

```bash
python3 -m http.server 8765
```

Then open http://localhost:8765. Deployed with GitHub Pages from the `main` branch to https://tambatech.ai.

Contact: info@tambatech.ai
